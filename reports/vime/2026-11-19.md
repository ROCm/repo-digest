**DeepSeek-V4 RL support roadmap (#525–#531)**

- [#525](https://github.com/vllm-project/vime/issues/525) (open): Combined roadmap and RFC for DeepSeek-V4 **RL** support. It starts with DeepSeek-V4-Flash using **Megatron**/Bridge training and **vLLM** **rollout**, with BF16 training, **FP8** rollout, **MTP** disabled at first, and CP=1 with short context. Replay data would include token IDs, logprobs, MoE router choices, DSA indexer top-k, sampling masks, and weight versions. V4-Pro, V4.1, native **FP4** training/refit, **speculative decoding**, and 1M-token context are out of scope for the first release.
- [#526](https://github.com/vllm-project/vime/issues/526) (closed): P0 milestone to pin dependencies (PyTorch, Triton, Transformer Engine, Megatron, Bridge, vLLM, container digest) and reproduce an existing vime baseline. It also compares the Bridge and mbridge paths to pick one.
- [#527](https://github.com/vllm-project/vime/issues/527) (closed): P1 milestone covering a DeepSeek-V4 model provider and HF↔Megatron **checkpoint** conversion. Scope includes CSA/HCA attention, compressor, DSA indexer, mHC, MoE routing, and a four-layer parity fixture.
- [#528](https://github.com/vllm-project/vime/issues/528) (closed): P2 milestone for V4 training kernels plus MoE router replay and DSA indexer top-k replay, so training reuses the routing decisions captured during rollout.

**Weight-update verification**

- [#537](https://github.com/vllm-project/vime/issues/537) (open, labeled `question`): RFC to implement `--check-weight-update-equal` for the vLLM backend. The flag is inherited from slime, but `check_weights()` is currently unimplemented in the vLLM adapter. The proposal runs checksum → reset → initial actor **weight sync** → compare through vLLM's `POST /weight_checker` API for each selected endpoint, including prefill/decode engines. Startup would fail with per-engine, rank, and tensor mismatches. It also adds a `--weight-checker-timeout` option (default 300s). The implementation is proposed in PR #533, which is not merged into `main`.
